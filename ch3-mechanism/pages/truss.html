MODULE 3-1・桁架結構

桁架結構解算

橋梁、屋架、起重機骨架,背後幾乎都是「桁架」。它用最少的材料,撐起最大的負載——關鍵就在三角形。

桁架是什麼?

桁架(Truss)是由一根根桿件(member),在端點以 節點(joint)連接而成的結構。它的核心是三角形——三角形是 三邊長度固定後、形狀就唯一確定(不會歪斜)的多邊形,所以桁架特別穩固。

桁架受力時,每根桿件只承受沿桿件方向的力,不是被「拉長」(張力)、 就是被「壓短」(壓力)。分析桁架,就是要算出每根桿件到底承受多大的張力或壓力。

🧪 動手操作:桁架受力視覺化

三種桁架,受力大不同

切換三種經典桁架,調整中央載重,觀察每根桿件的受力狀態—— 紅色=張力(被拉)、 藍色=壓力(被壓),線條越粗代表受力越大。

💡 知識小百科

三種經典桁架的差異

Pratt(普拉特式):斜桿朝中央向下傾斜。受力時斜桿為張力、直桿為壓力。 因為較長的斜桿承受張力(鋼材抗拉性佳),最省鋼材,是鋼橋最常見的形式。
Howe(豪氏):斜桿方向與 Pratt 相反。受力時斜桿為壓力、直桿為張力, 較適合木造桁架(木材抗壓性佳)。
Warren(華倫式):斜桿呈 W 形交錯,沒有直桿(或只有少數)。斜桿 張力、壓力交替出現,結構簡潔、桿件數少。

節點法(Method of Joints)

上面的模擬器直接把答案畫給你看,但工程師是怎麼「手算」出每根桿力的? 最基本的方法叫節點法:把桁架的每個節點單獨切出來畫自由體圖。 節點是一個「點」,不會旋轉,所以每個節點只需要兩條平衡方程式 ΣFx = 0、ΣFy = 0 就能求解; 解完一個節點,把結果帶到相鄰節點,像推骨牌一樣把整座桁架逐一解完。 靜定桁架(n = 0)用節點法就能全部解出——這正是「靜定」的意義。

⚠️ 重要提醒

每個節點只能解 2 個未知數

一個節點只有 ΣFx、ΣFy 兩條方程式,所以一次最多解 2 個未知力。 因此解題要從「未知桿力不超過 2 根」的節點下手——通常是支承節點 (反力已先由整體平衡求出)。若某節點掛了 3 根未知桿件,就先去解別的節點,回頭再處理它。

✏️ 動手解:節點法逐步解算

三步解出等腰三角桁架的桿力

題目:等腰三角桁架,跨距 4 m、高 1.5 m;左端 B 為鉸支承、右端 C 為滾支承, 頂點 A 承受向下載重 P = 100 kN。 由對稱性,兩支承反力各為 50 kN(向上)。 斜桿長 = √(2² + 1.5²) = 2.5 m,故 sinθ = 1.5/2.5 = 0.6、cosθ = 2/2.5 = 0.8。

步驟 ①

取左支承節點 B,畫自由體圖

節點 B 只接了 2 根桿件(斜桿 AB、下弦桿 BC),未知數剛好 2 個,從這裡下手。 把 B 切出來,畫出作用在它身上的三個力——先假設兩根桿都是張力 (箭頭沿桿方向離開節點);若算出負值,就代表其實是壓力。

步驟 ②

ΣFy = 0:解斜桿力 FAB

垂直方向只有兩個力:反力 50 kN(向上)與 FAB 的垂直分量 FAB·sinθ。 列式 50 + FAB × 0.6 = 0,解出 FAB。 (提示:sinθ = 1.5/2.5 = 0.6;大小取絕對值填入,再選它是張力還是壓力)

🧮 動手算:靜定判斷計算器

這個桁架是靜定還是靜不定?

用公式 n = b + r − 2j 判斷:b 桿件數、r 反力數、j 節點數。 輸入數值,看計算結果。 r 怎麼數?每種支承提供的反力分量數不同——見 靜力學頁的「支承類型與反力數」小卡(滾支承 1、鉸支承 2、固定端 3)。

b 桿件數 r 反力數 j 節點數
深入探究:n < 0、n = 0、n > 0 各代表什麼?

n < 0(不穩定):桿件不夠,結構會垮掉——這不是合格的結構。
n = 0(靜定):桿件剛剛好,可用基礎平衡方程式完全解出每根桿件的力。
n > 0(靜不定):桿件「多」了,光靠平衡方程式解不出來,需要再考慮材料變形 ——這時就要靠電腦的 FEA 分析。多出來的桿件雖然增加分析難度,卻也讓結構更穩固、更安全。
