必考自由體圖 FBD:結構分析的第一步

Free Body Diagram|把物體從環境中「分離」出來,繪出施加在物體上的所有外力

畫 FBD 要標出三種東西

  • 主動力:負載、重力(把東西往下拉的)
  • 反作用力:支撐力、連接力(撐住它的)
  • 力矩:讓它轉動的效應

「第一步,也是最重要的一步」

把分析的物體(或其一部分)從周圍環境「分離」出來。簡支樑範例:中間負載 P 向下,兩端支撐點 A、B 各有向上反力 RA、RB。

課堂練習:畫「掛在牆上的層板」的 FBD(重力+牆的支撐+螺絲拉力)。

3-1-1三條平衡方程式

「若物體處於靜止平衡狀態,則其所受淨力與淨力矩均為零。」——國中已學概念,高中進入量化計算
ΣFx = 0水平方向淨力為零
ΣFy = 0垂直方向淨力為零
ΣM = 0對任一點的淨力矩為零
示範:對稱簡支樑,中央負載 P → 由 ΣFy=0 與 ΣM=0 解得 RA = RB = P/2。實作上常把 3D 模型轉成 2D 平面分析,即可解出未知的支撐反力或內力。

關鍵轉折手算的極限

手算 OK

  • 靜止不動的結構
  • 支撐固定、受力單純
  • 形狀簡單(樑、簡單桁架)

手算爆炸

  • 不規則桁架、連續樑
  • 超靜定結構(未知數比方程式多)
  • 計算繁瑣,甚至無法完成
電腦模擬=快速、精確、有效率 ➜ 有限元素分析 FEA(Finite Element Analysis)登場

小百科靜不定結構:n = b + r − 2j

「冗餘」是備援,不是加分題|重繪自課本圖 3-2 數據(b=6、r=3、j=4)
n = b + r − 2j

b=桿件數(Bars)/r=反力數(Reactions)/j=節點數(Joints)
係數 2:2D 節點各有 x、y 兩條力平衡方程式

n = 0

靜定:方程式剛好解得出

n > 0

靜不定:n 即靜不定度(冗餘約束數)

課本範例

b=6、r=3、j=4 → n = 6+3−8 = 1(超 1 次靜不定)

正確理解「冗餘」:靜不定=有多餘的約束。好處:一根桿壞了還有備援,結構較不易垮(像四腳凳比三腳凳穩)。代價:未知數比方程式多、手算解不出,而且地不平時四腳凳會翹腳——冗餘也可能引入裝配應力。所以冗餘是「備援」,不能無條件說「越大越好」。

軟體不是魔法

它算的是材料庫裡的三個數字:

  • 楊氏模數
  • 蒲松比
  • 降伏強度

材料選錯,再漂亮的雲圖都是垃圾進垃圾出。下一段用生活例子看懂這三個數字。

小百科讀懂材料屬性三關鍵

考點:楊氏模數=彈性限度內「應力/應變」比值(剛性)

楊氏模數

剛性:抵抗變形的能力。鋼(硬、變形小)vs 橡膠(軟、變形大)。想要少變形,選高楊氏模數。

蒲松比

橫向變形 ÷ 縱向變形。拉麵條:變長的同時變細。金屬約 0.3,是體積變化計算的關鍵參數。

降伏強度

彈性 → 塑性的臨界點。安全紅線:最大應力超過降伏強度=永久變形、已損壞。

課堂教具:現場拉橡皮筋(回得來=彈性變形)vs 折迴紋針(回不來=塑性變形)——降伏強度就是那條界線。

3-1-2STEP 4–6:約束・負載・網格

失敗路徑|網格的取捨:網格越細越精確,但計算越久。太粗→結果失真;太細→算到天荒地老。工程做法:先粗算抓趨勢,再對高應力區局部加密。想一想:為什麼不直接用最細網格?

必考STEP 7:求解與三種結果圖

會看圖,才算會模擬

應力分布

馮·米塞斯應力(Von Mises stress)彩色雲圖——紅色高應力區=可能破壞處。它是「綜合應力指標,拿來跟降伏強度比」。

位移分布

整體變形情況+最大變形量,確認變形是否在可接受範圍。

安全係數

相對降伏強度的裕度。< 1 = 可能永久變形或破壞(紅線警報)。工程慣例:一般結構取 1.5–3,載人另計(超綱補充)。
