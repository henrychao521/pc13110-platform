5-1-2類比與數位:兩個世界

類比訊號 Analog

連續變化的物理量,隨時間平滑起伏,兩個值之間有無限多個值。

例:溫度、音量、光線亮度、水位、水銀溫度計的水銀柱

數位訊號 Digital

只有兩種(或有限個)離散狀態:0 與 1、LOW 與 HIGH。

例:電燈開關、按鈕、日曆的日期

隨堂判斷:哪些是數位訊號?

項目類比 / 數位理由
電燈開關數位 ✓只有開與關
水銀溫度計類比 ✗水銀柱連續上升
電梯按鈕數位 ✓按下 / 未按
光線亮度類比 ✗亮度可無限細分
日曆(日期)數位 ✓一格一格跳,是離散值
答案:3 個。「日曆」最常被漏掉——它不是連續變化,是一格一格跳的離散值。判斷訣竅:問自己「它中間有沒有無限多個值?」有 = 類比,只能跳格 = 數位。(習題 Q4)

重點ADC 解析度:切得越細,看得越清楚

同樣一段電壓,切成幾階?階距越小,量測越精準
4.88 mVArduino Uno 每階10 bit / 5V:0–1023,共 1024 階
5V ÷ 1024 = 4.88 mV
0.81 mVESP32 每階12 bit / 3.3V:0–4095,共 4096 階
3.3V ÷ 4096 = 0.81 mV
2ⁿ位元數變了,公式不變解析度 = 滿刻度電壓 ÷ 2ⁿ
讀值 = Vin ÷ V滿 × (2ⁿ − 1)
超綱補充|習題考的是 9 bit!課本只示範 10 bit 與 12 bit,課後習題卻用 9 bit——所以一定要教通式,不要背數字。
9 bit → 讀值範圍 0~511(共 512 階,習題 Q5);若 Vin = 2V、滿刻度 5V,答案:讀值 204(習題 Q6)。
詳解|兩種算法為什麼會差 1:
(a) 課本採用:讀值 = Vin ÷ Vref × (2ⁿ − 1) = 2 ÷ 5 × 511 ≈ 204.4 → 204。把「滿刻度 5V」對應到最大讀值 511,也就是 0V→0、5V→511 兩端點連成直線。
(b) 另一種常見寫法:讀值 = Vin ÷ Vref × 2ⁿ = 2 ÷ 5 × 512 = 204.8 → 205(四捨五入)。微控制器原廠資料表多用這一式,例如 Microchip ATmega328P(Arduino Uno 的晶片)資料表第 24.7 節「ADC Conversion Result」寫 ADC = Vin × 1024 ÷ Vref,並註明最大值 0x3FF(1023)代表「Vref 減 1 個 LSB」;Arduino 官方 analogRead() 說明也用「5 V ÷ 1024 階 ≈ 4.9 mV」當每階大小。
差異來源在 LSB(最小一階)怎麼定義:(b) 把 Vref 切成 2ⁿ 等份,1 LSB = Vref ÷ 2ⁿ,所以最大讀值 2ⁿ − 1 對應的是 Vref − 1 LSB,Vref 本身「讀不到」;(a) 則讓最大讀值恰好等於 Vref,等於把 1 LSB 當成 Vref ÷ (2ⁿ − 1)。兩式只差約 0.2%,結果最多差 1 階;實際 ADC 還會截去小數而不是四捨五入(204.8 在晶片裡會存成 204)。本講義與課本一致,答案以 204 為準;看到 205 的算法時,要能說出它用的是 × 2ⁿ。
出處:Microchip,ATmega48A/PA/88A/PA/168A/PA/328/P 資料表(DS40002061B) §24.7;Arduino,analogRead() 官方說明。
比喻:同一支尺,一支只有公分刻度、一支有公釐刻度——量的是同一段長度,但看得清楚的程度差很多。位元數就是尺上的刻度密度。

重點PWM:用開關的節奏假裝類比

重製自課本圖 5-5|數位腳位只有 0 和 1,怎麼做出「半亮」?

工作週期 Duty Cycle

工作週期 = T1 ÷ T × 100%

T1 = 高電位持續時間,T = 一個完整週期

同樣手法,兩種用途

LED:工作週期越大 → 越亮
直流馬達:工作週期越大 → 轉越快

DAC 的兩條路

專用 DAC IC:真類比、效果好、成本高
PWM:模擬類比、便宜普及

多數控制板走 PWM 這條路;ESP32 是少數兩條路都有的板子(內建 2 組真 DAC)。
頻率 = 1 ÷ 週期。例:高電位 75 ms + 低電位 25 ms = 週期 100 ms = 0.1 秒 → 頻率 10 Hz(習題 Q9)。
埋梗|PWM 一詞五用:這一招在第 5 章會出現五次——① DAC 模擬類比 ② LED 調光 ③ 馬達調速 ④ 伺服馬達角度 ⑤ 蜂鳴器音高。5-3 有一頁專門統整。

5-1-3Arduino 家族與 IoT 浪潮

Arduino 的開源精神

  • 軟體與硬體皆開源,人人可改可做
  • 支援 C/C++、microPython、圖形化語言
  • 龐大的模組函式庫與社群範例
  • 容易與 Processing、手機 App 互動
家族成員:UNO / Nano / Mini / Mega / Due——尺寸、腳位數、效能各異,但程式寫法相通。

轉折:「能連網」變成基本需求

工業 4.0 + IoT 時代,沒有通訊能力的 Arduino Uno 逐漸被 ESP32 取代。

  • 內建 WiFi + 藍牙——不必外接通訊模組
  • 雙核心 240 MHz——比 Uno 的 16 MHz 快 15 倍
  • 真 DAC × 2 組——能輸出真正的類比電壓
→ 所以本書 5-3 節的主角就是 ESP32。
勘誤提醒:ESP32 主頻率一律講 240 MHz(以課本表 5-3 為準;5-3-1 內文寫「260 MHz」為誤植)。另外課本表格中的「Adruino Uno」為原文錯字,正確拼法是 Arduino Uno。

實作隨堂實作:LED 閃滅(Tinkercad)

接線:D10 → 330Ω 電阻 → LED 長腳(正極) → LED 短腳 → GND
麵包板最常錯的兩點:中間區每 5 孔縱向連通、上下電源軌橫向連通;LED 長腳為正極。

程式四個關鍵

// 亮 0.5 秒 → 滅 0.5 秒 → 無限循環
void setup() {
  pinMode(10, OUTPUT);   // 宣告 D10 為輸出腳(只跑一次)
}
void loop() {
  digitalWrite(10, HIGH); // 送出高電位 → 燈亮
  delay(500);            // 停留 500 毫秒 = 0.5 秒
  digitalWrite(10, LOW);  // 送出低電位 → 燈滅
  delay(500);            // loop 會無限重複
}
setup() 與 loop():setup() 在通電或按下 Reset 後只執行一次,用來做初始設定;loop() 接著無限重複執行。(習題 Q7 考 pinMode 寫法、Q8 考 Reset 後先跑 setup())

失敗路徑1Ω 的代價:為什麼一定要串限流電阻?

  1. ①
    嘗試想讓 LED 更亮,把 330Ω 換成 1Ω
  2. ②
    失敗Tinkercad 跳出驚嘆號:LED 電流已超過 20 mA(真實世界=當場燒毀)
  3. ③
    改用用歐姆定律算最小電阻:R = (5V − 1.8V) ÷ 20mA = 160Ω → 選 330Ω 更保險
  4. ④
    學到電阻太大 → LED 變暗;太小 → 燒毀。模擬器的價值:燒掉也不心痛

關鍵已知條件

  • 紅色 LED 順向壓降 ≈ 1.8V
  • LED 額定電流 ≈ 20 mA
  • 電源 5V

R = (V電源 − V壓降) ÷ I

不同顏色的 LED 壓降不同(藍色、白色約 3V)。可以問學生:換成藍色 LED,電阻要算多大?
